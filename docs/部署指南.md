# 部署指南

本文档覆盖两种部署方式：单机部署（推荐用于评审演示）与 Docker Compose。

---

## 一、前置条件

- JDK 17+（推荐 21）
- Node.js 18+ 与 npm
- MySQL 8.0+
- （可选）Playwright Chromium：用于岗位/题库抓取与链接导入

---

## 二、单机部署

### 1. 数据库

```sql
CREATE DATABASE chuan DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

表结构由后端启动时自动创建，无需手工导入。

### 2. 后端

```bash
cd backend
mvn -DskipTests package
```

配置环境变量（Linux 示例，Windows 用系统环境变量或在 IDEA 中配置）：

```bash
export DB_PASSWORD='你的数据库密码'
export JWT_SECRET='至少32位随机字符串'
export DEEPSEEK_API_KEY='sk-...'
export DASHSCOPE_API_KEY='sk-...'
export WEBSOCKET_ALLOWED_ORIGINS='https://你的域名'
# 可选：简历归档目录，默认 ~/.chuan/resumes
export APP_RESUME_DIR='/data/offergo/resumes'
```

启动：

```bash
java -jar target/chuan-backend-0.0.1-SNAPSHOT.jar
```

如需抓取功能，先安装 Playwright 浏览器：

```bash
backend/install-playwright.cmd        # Windows
# Linux/macOS：使用 Playwright Java CLI 安装 chromium
```

### 3. 前端

```bash
cd frontend
npm ci
npm run build      # 产物在 dist/
```

将 `dist/` 交给 Nginx 托管，并把 `/api` 与 `/ws` 反代到后端：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/offergo;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}
```

### 4. 系统服务（可选）

使用 systemd 托管后端，保证评审期间可用：

```ini
[Unit]
Description=OfferiGo Backend
After=network.target mysql.service

[Service]
User=offergo
EnvironmentFile=/etc/offergo/env
ExecStart=/usr/bin/java -jar /opt/offergo/chuan-backend.jar
Restart=always

[Install]
WantedBy=multi-user.target
```

## 三、Docker Compose 部署

仓库 `deploy/` 下提供了示例文件：

- `deploy/backend.Dockerfile`
- `deploy/frontend.Dockerfile`
- `deploy/nginx.conf`
- `deploy/docker-compose.yml`

```bash
cp .env.example .env     # 填写数据库密码、JWT、模型 Key
docker compose -f deploy/docker-compose.yml up -d --build
```

访问 `http://服务器IP`。

> 注意：容器内默认不安装 Playwright 浏览器，抓取类功能会降级（推荐列表为空时不会影响其他模块）。需要抓取时在 backend 镜像中安装 Chromium 并挂载数据目录。

## 四、评审演示准备清单

- [ ] 创建评审专用账号，准备一份示例简历素材与 2 个岗位
- [ ] 确认首页 → 岗位匹配 → 定制简历 → 求职信 → 模拟面试 → 笔试 → 投递台账全流程可走通
- [ ] 在线地址使用 HTTPS（麦克风权限要求安全上下文）
- [ ] 评审期间保持服务与数据库可用
- [ ] 关闭或调整每日定时抓取时间，避免评审时占用资源

## 五、常见问题

**麦克风/摄像头无法使用**：浏览器要求 HTTPS 或 localhost，非安全上下文会拒绝授权。

**WebSocket 连不上**：检查 Nginx 是否转发 `Upgrade`/`Connection` 头，以及 `WEBSOCKET_ALLOWED_ORIGINS` 是否包含实际域名。

**抓取失败**：多数为源站反爬或未安装 Playwright 浏览器；不影响已有数据与其他模块。

**时区不一致**：数据库连接串已固定 `serverTimezone=Asia/Shanghai`，服务器也建议设置为 Asia/Shanghai。
