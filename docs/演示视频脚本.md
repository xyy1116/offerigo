# 演示视频脚本（5–8 分钟）

> 目标：让评委在 6 分钟内看懂「真实痛点 → 完整闭环 → AI 技术深度 → 创新点」。
> 录制建议：1920×1080，普通话讲解，可加字幕；提前登录并准备好演示数据。

## 0. 开场（0:00–0:30）

- 画面：首页 Hero 与产品名
- 解说：
  「大家好，我们是 OfferiGo。我们做的不是又一个简历模板网站，而是一个用 AI 串起完整求职链路的求职工作台：从简历素材、岗位推荐与匹配，到定制文书、模拟面试、笔试训练和投递跟进。」

## 1. 项目介绍与痛点（0:30–1:20）

- 画面：首页痛点区、流程图
- 解说：
  「毕业生求职有三个典型问题：不知道哪个岗位适合自己；不知道怎么把真实经历讲清楚；面试和笔试缺少针对性训练。我们的做法是：以一份可复用的简历素材库为事实来源，让 AI 在整条链路上做匹配、生成、演练和复盘。」

## 2. 简历素材库（1:20–2:00）

- 操作：展示素材分类；导入一份简历或粘贴长文本，演示 AI 拆分
- 解说要点：
  - 六类素材结构化存储
  - 导入、拆分、增量补充
  - 「素材一处更新，全站生效」

## 3. 岗位获取与匹配（2:00–3:00）

- 操作：
  1. 「最新推荐」展示每日 TOP10
  2. 加入我的收藏
  3. 打开匹配卡片，展示四维分数、匹配优势、待补足项
  4. 展示 90 分以上的高亮样式
- 解说要点：
  - 每日 08:00 自动更新；支持粘贴/链接/文档/截图导入
  - 本地确定性引擎 + AI 评估双轨：分数稳定、可解释
  - 每条结论都能追溯到具体简历素材

## 4. 定制文书（3:00–4:00）

- 操作：打开「求职小精灵」→ 匹配评估 / 定制简历 / 求职信
- 演示：选择模板、生成定制简历、预览、导出 PDF；生成求职信
- 解说要点：
  - 基于向量检索选出最相关素材（RAG），再交给大模型生成
  - 阶段化进度可视化，不是假进度
  - 禁止编造经历，只优化表达

## 5. AI 模拟面试（4:00–5:00）

- 操作：进入面试间，授权麦克风，回答一个问题，结束查看报告
- 解说要点：
  - 岗位定向提问
  - 实时语音识别（Paraformer）
  - 结束后生成多维报告，历史可复盘

## 6. AI 笔试助手（5:00–5:40）

- 操作：展示题库规模 → 生成一份 10 题试卷 → 提交 → 错题本
- 解说要点：
  - 按岗位匹配真题，自由练习 / 限时模拟
  - 错题归档、重做、标记掌握
  - 题库每日 08:00 更新

## 7. 投递与跟进（5:40–6:10）

- 操作：投递台账 → 上传当次简历 → 修改状态 → 跟进提醒
- 解说：投递记录、简历归档、状态与提醒统一管理

## 8. 技术亮点与收尾（6:10–7:00）

- 画面：架构图 / 终端 / 代码片段
- 解说要点（挑 3 个讲）：
  1. 双轨评分：确定性引擎保证稳定，AI 提供深度分析
  2. RAG：素材向量检索 + 大模型生成，引用可追溯
  3. 多模态：截图识别 JD、实时语音面试
  4. 工程：Spring Boot + Vue 3，JWT 鉴权、阶段化任务、亮暗双主题
- 收尾：
  「OfferiGo 希望让每一次投递都更有把握。谢谢观看。」
